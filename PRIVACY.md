# Политика конфиденциальности приложения MB-CAL

**Дата последнего обновления:** 29 марта 2025 г.

Приложение **MB-CAL** («Инженерный CAS калькулятор», `io.github.markhoodwink.mbcal`) соблюдает полную конфиденциальность пользователей и гарантирует безопасность ваших данных.

---

## 1. Сбор и обработка персональных данных

Приложение **MB-CAL** **НЕ собирает, НЕ хранит и НЕ передаёт** третьим лицам или на внешние серверы никакие персональные данные пользователей, идентификаторы устройств, телеметрию, аналитику или рекламные идентификаторы. 

Все математические вычисления, решение уравнений, построение графиков и распознавание формул выполняются **строго локально на вашем устройстве**.

---

## 2. Разрешения и их использование

Приложение запрашивает только минимально необходимые системные разрешения для обеспечения заявляемого функционала:

- **Камера (`android.permission.CAMERA`)**:
  Используется исключительно во время работы функции сканера формул для получения снимка математического выражения с помощью камеры вашего устройства. Изображения обрабатываются локально нейросетевым движком ONNX Runtime на устройстве и **никогда не передаются на внешние серверы**.

- **Доступ к сети Интернет (`android.permission.INTERNET`)**:
  Используется исключительно по явной инициативе пользователя в двух случаях:
  1. Загрузка офлайн-модели распознавания формул (~120 МБ) с официального репозитория GitHub Releases при первом включении сканера.
  2. Проверка наличия новых версий приложения на GitHub Releases (только в сборках для GitHub, в сборках для RuStore автозагрузка обновлений отключена).

- **Вибрация (`android.permission.VIBRATE`)**:
  Используется для тактильного отклика (виброотдачи) при нажатии виртуальных клавиш калькулятора.

---

## 3. Файлы и хранение данных

Все пользовательские настройки, история вычислений и константы сохраняются исключительно во внутреннем изолированном хранилище приложения на вашем устройстве (SharedPreferences / Internal Storage). Вы можете в любой момент очистить эти данные в настройках системы Android.
