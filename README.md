# MB-CAL — Инженерный CAS-калькулятор и математический комбайн для Android

[![GitHub release](https://img.shields.io/github/v/release/Markhoodwink/Calculator?color=blue&label=Релиз)](https://github.com/Markhoodwink/Calculator/releases/latest)
[![Build Status](https://img.shields.io/github/actions/workflow/status/Markhoodwink/Calculator/release.yml?label=Сборка)](https://github.com/Markhoodwink/Calculator/actions)

**MB-CAL** — это мощный инженерный и учебный калькулятор для Android, созданный для решения школьных и университетских задач по математике, физике и инженерным дисциплинам, а также для подготовки к ЕГЭ.

[📥 **Скачать последний APK (Releases)**](https://github.com/Markhoodwink/Calculator/releases/latest)

---

## ✨ Что нового в версии 2.2

- **Раскрытие сложных радикалов в CAS**: Автоматическое выделение полного квадрата под корнем по формуле сложного радикала (`√(5 + 2√6) = √3 + √2`, `√(7 - 4√3) = 2 - √3`, `√(5 + 2√6) - √(5 - 2√6) = 2√2`) с подробным шагом разбора.
- **Классическая логика после `EXE =` (как в Casio)**: Нажатие оператора (`+`, `−`, `×`, `÷`, `x²`, `x^□`, `x!`) после ответа автоматически подставляет `Ans` (включая точные символьные ответы вроде `√3 + √2`), ввод цифры/функции начинает новый расчёт, а стрелки, `DEL` или тап по формуле возвращают в режим редактирования.
- **Настраиваемые параметры графиков в стиле Desmos**: Произвольный шаг параметра (десятичные числа, дроби `1/4`, `π/4` или плавный режим), свои границы «От/До», пресеты шага и кнопки точного сдвига `−`/`+` на один шаг.
- **Системы счисления в Конвертере величин**: Новая категория на первом месте в списке (`BIN (2)`, `OCT (8)`, `DEC (10)`, `HEX (16)` и основания `3–12`) с динамической клавиатурой `A–F`, поддержкой дробей, отрицательных и больших 64-битных чисел.
- **Улучшения решателя неравенств ЕГЭ №15**: Поддержка переменных оснований `b ≠ 1`, точное нахождение больших (`125`, `625`, `1024` и до `10⁵`) и дробных (`1/625`) логарифмических корней.
- **Обновлённое окно обновлений**: Нативный диалог в стиле светлой и тёмной тем MB-CAL с автоматической загрузкой списка изменений.

## ✨ Что нового в версии 2.1

- **Адаптивные (векторные) скобки и модули**: Автоматическое масштабирование высоты скобок `( )`, прямых скобок модуля `| |` и аргументов логарифма `log_a(...)` под высоту вложенных дробей, корней и матриц во всех режимах (CAS, Решатель неравенств, Сканер формул).
- **Поддержка модулей и кнопка `|x|`**: Полноценная кнопка ввода модуля `|x|` на клавиатуре CAS, символьное решение уравнений и неравенств с модулями (включая вложенные `||x| - 2| = 1`), с сохранением знаковой точности.
- **Знаково-логарифмический решатель неравенств**: Устойчивый символьный метод рационализации логарифмических и показательных неравенств без риска переполнения разрядов.
- **Распознавание радикалов высших степеней**: Офлайн OCR сканер теперь распознает квадратичные и высшие радикалы вида `⁴√2 - 2` и сложные составные выражения.
- **Автоматическая проверка обновлений**: Встроена безопасная проверка свежих релизов с GitHub Releases (`UpdateChecker`) с уведомлением пользователя при наличии новой версии.

## ✨ Что нового в версии 2.0

- **100% офлайн-сканер формул**: Распознавание математических выражений с помощью нейросетевого движка `Pix2Text-MFR 1.5` через ONNX Runtime + XNNPACK (опциональная разовая загрузка ~120 МБ).
  - Два режима распознавания: `📄 Печать` (печатный текст/учебники) и `✍️ Тетрадь` (рукописный ввод с алгоритмом удаления наклонной тетрадной клетки для гелевой/синей ручки и карандаша).
  - Улучшенная предобработка: автоматическая инверсия тёмной темы, адаптивный авто-повтор при сбоях, отсев номеров заданий и муара.
  - Камера и Галерея: поддержка тап-фокуса, зума `1x/2x`, обрезки и поворота `↻ 90°` при импорте из галереи.
  - Интерактивный контроль: 2D-редактор проверки в стиле CAS, режим просмотра «глазами ИИ» и скрываемая по тапу телеметрия.
- **Расширенный CAS-решатель логарифмических уравнений**: Приведение степенных и алгебраически равных переменных оснований, точное тождество `1/logₐ(b) = log_b(a)`, а также строгая проверка ОДЗ логарифмов и оснований.
- **Улучшения тригонометрии**: Поддержка многоэтажных дробей `\cfrac`, котангенса `ctg`, а также углов с шагом `π/8`.
- **Стабильность и Android 15+**: Исправлена горизонтальная прокрутка в `CasioDisplayView`, добавлена поддержка размерности страниц памяти 16 KB (Android 15+) и обновлён `onnxruntime-android:1.32.0`.

## 🚀 Основные возможности

1. **CAS-калькулятор, комбинаторика и 2D-дисплей**:
   - Естественный ввод математических выражений (дроби, корни, степени, скобки, 2D-шаблон комбинаторики $C_n^k$ / $A_n^k$).
   - Интерактивный курсор по тапу на холсте `CasioDisplayView`.
   - Мгновенный тактильный отклик Pixel-клавиатуры (`ACTION_DOWN`) и асинхронный живой предвывод.
   - Быстрое переключение формата `S⇔D` (точная обыкновенная дробь / десятичное число).
   - Расширенный CAS-решатель уравнений (показательные с заменой, иррациональные, логарифмические, модульные, биквадратные, чётные/нечётные степени) с автоматической проверкой ОДЗ и выезжающей шторкой пошагового разбора.
   - Вычисления без переполнения на `BigInteger` (`50!`, `2^65`) и упрощение степеней с радикалами.

2. **Тригонометрия (ЕГЭ)**:
   - Интерактивная тригонометрическая окружность (Unit Circle) с визуализацией углов и точек.
   - Автоматический отбор корней на заданном отрезке $[a; b]$.
   - Подробный пошаговый разбор решений для **Пункта а)** (все корни) и **Пункта б)** (корни на отрезке).

3. **Системы уравнений**:
   - Точное решение линейных систем от 2 до 5 переменных.
   - Школьный пошаговый разбор методом подстановки.
   - Решение нелинейных систем уравнений $2 \times 2$.

4. **Графики функций**:
   - Интерактивный 2D-плоттер функций в стиле Desmos.
   - Автоматический поиск корней (нулей функции), экстремумов (минимумов и максимумов) и точек пересечения графиков.
   - Построение динамической таблицы значений.

5. **3D-сечения многогранников**:
   - Построение и визуализация сечений куба, пирамиды, призмы и тетраэдра.
   - Точная видимость передних и задних рёбер и граней.
   - Жестовое вращение и масштабирование 3D-модели.
   - Автоматическая достройка плоскости сечения по заданным точкам.

6. **Матрицы**:
   - Точные матричные вычисления на обыкновенных дробях.
   - Вычисление определителя $\det(A)$, нахождение обратной матрицы $A^{-1}$, транспонирование $A^T$.
   - Матричная арифметика (сложение, вычитание, умножение матриц и скаляров).

7. **Конвертер величин**:
   - 10 категорий физических и информационных единиц (длина, масса, объём, давление, энергия, скорость, память и др.).
   - Мгновенный пересчёт между системами счисления и единицами.

8. **Удобство, константы и персонализация**:
   - Полная поддержка тёмной и светлой тем оформления через `ThemeManager`.
   - История вычислений с возможностью повторного использования результатов.
   - Встроенный справочник школьных физических (ЕГЭ: `g = 10`, `R = 8.31`, `k = 9·10⁹`, `Nₐ = 6·10²³`) и фундаментальных математических констант.

## 🛠 Стек технологий

- **Язык**: Kotlin
- **Платформа**: Android SDK (Android XML Views + кастомные 2D/3D Canvas компоненты)
- **UI Framework**: Material Components
- **CAS Engine**: Собственный символьный движок на точных рациональных дробях (`Fraction`), `BigInteger` и дереве AST (`Node`)
- **Тестирование**: JUnit4 unit-тесты для математических движков

## 🛠 Сборка из исходников

Для сборки проекта и запуска unit-тестов требуется JDK 17+.

```bash
# Запуск юнит-тестов математических движков
./gradlew testDebugUnitTest

# Сборка отладочного APK
./gradlew assembleDebug
```

Готовый APK-файл после сборки будет находиться по пути:
`app/build/outputs/apk/debug/app-debug.apk`
